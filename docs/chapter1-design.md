# 챕터 1 플레이 규칙 (AI 구현 명세)

이 문서는 `ai/rhythm-ch1` 브랜치에서 구현한 챕터 1의 실제 동작 규칙이다. 기획 문서([README](../README.md))의 "살금살금 걷기"를 다음 해석으로 확정했다.

> 캐릭터는 스스로 앞으로 걷는다. 음악이 "멈춰야 할 박"(쉼표)을 정하고, 플레이어는 그 박에 정확히 클릭해서 멈춘다. 놓치면 발소리가 나고, 엉뚱한 박에 누르면 헛발이 된다.

레인 UI는 넣지 않았고, 박자를 보여 주는 시각 표시도 넣지 않았다. 소리만 듣고 맞춘다.

## 1. 진행

```
내 방(침대) → 거실 → 부엌(싱크대) → 물 마시기 → 부엌 → 거실 → 내 방(침대)
```

- 방 3개를 이어 붙여 두고 카메라가 따라간다. 방 폭은 40 units(4000 px, PPU 100).
- 방 경계를 넘으면 다음 방으로 이동한다.
- 물을 마시면 진행 속도가 5.0 → 6.5 units/s로 빨라진다(기획: "부엌 구간부터 진행 속도가 빨라진다").
- 침대로 돌아오면 성공.

## 2. 박자

| 항목 | 값 | 위치 |
| --- | --- | --- |
| BPM | 80 (1박 = 0.75초) | `GameConfig.Bpm` |
| 리드인 | 1.6초 | `GameConfig.LeadInSeconds` |
| 멈춤 박 패턴 | 16박 주기 중 3개 (2, 8, 11번) | `GameConfig.RestPattern` |
| Perfect | ±60 ms | `GameConfig.PerfectWindow` |
| Good | ±120 ms | `GameConfig.GoodWindow` |
| 정지 유지 | 1박 | `GameConfig.StopHoldBeats` |

멈춤 박은 낮은 음(620 Hz)으로, 일반 박은 높은 음(1200 Hz)으로 울린다. 오디오 파일은 저장소에 없으므로 `Metronome.cs`가 파형을 만들어 `AudioSettings.dspTime`에 예약 재생한다.

## 3. 소음

| 행동 | 소음 | 비고 |
| --- | --- | --- |
| Perfect로 멈춤 | 0 | |
| Good으로 멈춤 | 1 | |
| 엉뚱한 박에 클릭 | 3 | 헛발 |
| 멈춤 박을 지나침 | 7 | 삐걱, 0.12초 휘청 |

소음은 방 계수(내 방 0.6 / 거실 1.0 / 부엌 1.3)를 곱해 누적된다. 정지 중에는 초당 1.5, 이동 중에는 초당 0.4씩 감소한다.

게이지가 100에 닿거나 제한 시간 75초를 넘기면 실패한다.

## 4. 물 마시기

부엌 싱크대(x=20)에 도착하면 자동으로 서고, Perfect 판정 3회 연속을 요구한다. Good이나 헛발이 나오면 연속이 끊긴다. 3회를 채우면 물을 마시고 방향을 돌린다.

## 5. 화면

- 카메라: orthographic size 5.4, 스프라이트 PPU 100 → 1080p에서 1:1 픽셀 매핑.
- 배경 바닥선: world y = -3.62. 프롭은 알파 하단 여백을 기준으로 잡은 피벗 덕분에 바닥에 붙는다(`SneakWalkAssetSetup.cs`).
- 프롭 스케일: `PropCatalog.cs`의 배율로 보정한다(소파 0.39, 싱크대 0.39 등). 원본 PNG는 건드리지 않았다.
- UI: 소음 게이지, 남은 시간, 방 이름, 목표 문구, 판정 플래시. 한글은 OS 폰트(맑은 고딕)를 동적으로 사용한다.

## 6. 코드 구조

## 7. 검증

- EditMode 10개, PlayMode 4개 테스트 통과 (`Assets/Tests`).
- 자동 플레이 테스트가 챕터를 실제로 완주한다: 성공, 38.7초, 소음 0.
- Windows 빌드 성공, 실행 파일이 엔진 초기화까지 정상.

## 8. 아직 정하지 않은 것

- 손맛 보정: 입력 지연(오디오 지연) 상수는 0으로 두었다. 실제 플레이에서 판정이 늦게 느껴지면 `GameConfig`에 오프셋을 넣어야 한다.
- 난이도 곡선: 지금은 16박 패턴이 고정이다. 챕터 진행에 따라 패턴을 조밀하게 만드는 단계가 없다.
- 챕터 2(아빠 라면): 조리 리듬 게임 규칙은 별도 설계가 필요하다.
- 시각 박자 표시: 요청대로 넣지 않았다. 접근성 옵션으로 추가할지는 결정이 필요하다.
