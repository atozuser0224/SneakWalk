# 기획 문서

SneakWalk의 기획 문서를 이 폴더에 정리합니다.

현재 프로젝트의 핵심 콘셉트와 챕터 아이디어는 [프로젝트 README](../README.md)에 있습니다. 세부 기획은 다음 주제를 중심으로 추가합니다.

- 챕터별 목표와 이동 동선
- 살금살금 걷기의 입력 방식과 타이밍·리듬 규칙
- 이벤트의 발생 조건과 플레이 방식
- 2D 화면 구성과 UI

간단한 그림 기획과 스케치는 [`drawed/`](../drawed/README.md)에 올립니다. 글로 설명하기 어려운 화면 구성이나 이동 동선은 그림으로 정리하고, 관련 기획 문서에서 링크합니다.
