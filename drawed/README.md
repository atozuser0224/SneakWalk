# 그림 기획

글로 설명하기 어려운 아이디어를 빠르게 그려 정리하는 폴더입니다. 완성도보다 의도와 흐름이 잘 보이는 것을 우선합니다.

## 무엇을 그릴까요?

- 캐릭터의 모습이나 표정
- 배경과 화면 구성
- 플레이어가 지나갈 이동 경로
- 이벤트가 일어나는 장면과 순서
- 메뉴와 게임 내 UI 배치

## 파일 정리

그림은 PNG, JPG, SVG, PDF 형식으로 저장할 수 있습니다. 편집에 필요한 원본 파일은 선택적으로 함께 올려 주세요. 파일명에는 챕터나 주제와 내용을 알아볼 수 있게 적습니다.

예시: `ch01_이동경로.png`, `캐릭터_아빠.jpg`, `이벤트_물건줍기.pdf`, `UI_게임화면.svg`

그림에 짧은 설명이 필요하면 같은 이름의 Markdown 파일을 함께 두거나, 관련 글 기획에서 그림을 링크해 주세요.

- 글 기획: [Planning 폴더](../Planning/README.md)
- 게임에 실제로 넣을 아트: [Assets/Art 폴더](../Assets/Art/)
